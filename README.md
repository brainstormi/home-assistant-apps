# Home Assistant Apps

Repositorio de Apps (add-ons) propias para Home Assistant.

## Instalación

1. En Home Assistant: **Ajustes → Apps → Tienda de apps → ⋮ → Repositorios**.
2. Añade `https://github.com/brainstormi/home-assistant-apps`.
3. Las Apps de este repositorio aparecerán en la tienda.

## Apps

| App | Descripción |
|-----|-------------|
| [Avisos de alarma](avisos_alarma/) | Avisa a una lista de contactos cuando salta la alarma: llamadas por Asterisk, app de Home Assistant, correo y Telegram. |
